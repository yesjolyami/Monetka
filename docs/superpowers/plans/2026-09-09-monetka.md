# Monetka Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Monetka — a Vue/Inertia family budget app with shared workspaces, a single transaction ledger, goals, debts, limits, stats, and JSON/CSV/PNG export.

**Architecture:** Laravel 13 Vue starter kit (Inertia). Every money change goes through a single-purpose Action inside `DB::transaction`. `Workspace` is the tenant; `EnsureWorkspace` binds the current budget; balances are computed from `transactions` (never stored). Vue pages consume Inertia props; theme tokens follow Copilot Money character without cloning the brand.

**Tech Stack:** Laravel 13, PHP 8.3+, Fortify, Inertia 3, Vue 3, TypeScript, Tailwind, shadcn-vue, Pest, SQLite locally.

**Spec:** `docs/superpowers/specs/2026-09-09-monetka-design.md`

## Global Constraints

- UI copy is Russian.
- Do not write a project README (keep the starter kit README untouched).
- Amounts are `integer` minor units; never `float` in DB or balance math.
- One currency per workspace (`RUB` | `USD` | `EUR`); no FX.
- Roles: `owner` | `member` only; one owner per workspace.
- Transaction types: `income`, `expense`, `transfer`, `adjustment`, `goal_contribution`, `goal_withdrawal`, `debt_repayment`.
- `amount` > 0 except `adjustment` (signed delta).
- Personal accounts are visible to all workspace members.
- Category delete is forbidden while transactions reference it.
- Recurring templates do not auto-post (no cron).
- JSON backup `schema_version` is `1`; unknown newer version is rejected; no merge import.
- Visual: Instrument Serif + Geist; tokens from spec §7.1; light/dark/system.
- Money Actions: `public function execute(...): Model` inside `DB::transaction()`.
- Form Requests only; controllers pass `$request->validated()`.
- Follow starter-kit patterns: `#[Fillable]`, Wayfinder routes, Pest in `tests/Feature`.
- After adding PHP routes, use `route('name')` in tests; in Vue prefer Wayfinder generated helpers, or literal paths matching `routes/web.php` until generated.

```php
<?php

namespace App\Support;

use InvalidArgumentException;

final class Money
{
    public static function toMinor(string $decimal): int
    {
        $normalized = str_replace(["\u{00A0}", ' '], '', str_replace(',', '.', trim($decimal)));

        if (! preg_match('/^-?\d+(\.\d{1,2})?$/', $normalized)) {
            throw new InvalidArgumentException('Некорректная сумма.');
        }

        return (int) round(((float) $normalized) * 100);
    }

    public static function toDecimal(int $minor): string
    {
        return number_format($minor / 100, 2, '.', '');
    }
}
```

Note: `toMinor` uses string regex then a single `* 100` round for 2-decimal currencies only (spec v1: RUB/USD/EUR). Do not store the float.

```php
public function execute(User $user, string $name, string $currency): Workspace
{
    return DB::transaction(function () use ($user, $name, $currency) {
        $workspace = Workspace::query()->create([
            'name' => $name,
            'currency' => $currency,
        ]);

        $workspace->memberships()->create([
            'user_id' => $user->id,
            'role' => WorkspaceRole::Owner,
        ]);

        $user->forceFill(['current_workspace_id' => $workspace->id])->save();

        return $workspace;
    });
}
```

```php
public function handle(Request $request, Closure $next)
{
    $user = $request->user();
    $workspace = $user->resolveCurrentWorkspace();

    if ($workspace === null) {
        return redirect()->route('workspaces.create');
    }

    if ($user->current_workspace_id !== $workspace->id) {
        $user->forceFill(['current_workspace_id' => $workspace->id])->save();
    }

    $request->attributes->set('workspace', $workspace);

    return $next($request);
}
```

`HandleInertiaRequests::share` add:

```php
'workspace' => function () use ($request) {
    $user = $request->user();
    if (! $user) {
        return null;
    }
    $ws = $request->attributes->get('workspace') ?? $user->resolveCurrentWorkspace();
    if (! $ws) {
        return null;
    }

    return [
        'id' => $ws->id,
        'name' => $ws->name,
        'currency' => $ws->currency,
        'role' => $ws->roleFor($user),
    ];
},
'workspaces' => fn () => $request->user()
```
